## Descripción de la Solución

Este proyecto consiste en el desarrollo de una página web interactiva utilizando HTML, CSS y JavaScript, donde se aplican conceptos matemáticos relacionados con la serie Fibonacci y los números primos en situaciones del mundo real.

La página simula funcionalidades básicas de un banco digital:

- Verificación de PINs seguros mediante números primos
- Simulación de ahorro progresivo utilizando la serie Fibonacci
- Diseño visual moderno, ordenado y responsivo
- Resultados mostrados dinamicamente dentro de la página

El proyecto busca demostrar cómo las matemáticas pueden aplicarse en sistemas financieros, seguridad informática y planificación económica.

# Contexto del Problema

Actualmente los bancos digitales necesitan métodos más seguros para proteger la información de los usuarios y herramientas que ayuden a mejorar la administración financiera.

En este proyecto se utilizan:

- **Números primos** para validar PINs de acceso seguros.
- **Serie Fibonacci** para generar un sistema progresivo de ahorro mensual.

La aplicación permite al usuario interactuar con formularios y visualizar resultados de manera inmediata.
