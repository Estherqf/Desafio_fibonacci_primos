Introducción y Contexto

Actualmente los bancos digitales necesitan sistemas seguros para proteger la información de los usuarios y también herramientas que ayuden a mejorar la administración financiera.

En este proyecto se aplican conceptos matemáticos mediante JavaScript, HTML y CSS para simular situaciones reales relacionadas con un banco digital.

Los números primos son utilizados para validar PINs de acceso seguros, mientras que la serie Fibonacci permite generar un sistema progresivo de ahorro.

🔐

Seguridad Bancaria

El sistema analiza si un PIN ingresado por el usuario es un número primo.

Los números primos son importantes en informática y criptografía porque poseen propiedades útiles para sistemas de seguridad.

💰

Ahorro Inteligente

El banco propone un sistema de ahorro progresivo usando la serie Fibonacci.

Cada mes aumenta ligeramente la cantidad de dinero ahorrado, ayudando a generar un hábito financiero organizado.

Explicación de los Algoritmos

Algoritmo de Fibonacci

La serie Fibonacci inicia con los números 0 y 1.

Cada nuevo número se obtiene sumando los dos anteriores.

0, 1, 1, 2, 3, 5, 8, 13...

En este proyecto la serie se utiliza para calcular un ahorro progresivo mensual.

Algoritmo de Números Primos

Un número primo solamente puede dividirse exactamente entre 1 y sí mismo.

Para verificar si un número es primo, el programa cuenta cuántas divisiones exactas posee.

2, 3, 5, 7, 11, 13...

Si el número tiene exactamente dos divisores, entonces es considerado primo.

Conclusión

Las matemáticas son fundamentales en muchas áreas de la vida real, especialmente en la tecnología y los sistemas financieros.

Los números primos son recomendables para sistemas de seguridad porque ayudan en procesos de validación, criptografía y protección de información.

La serie Fibonacci permite crear modelos de crecimiento progresivo, siendo útil para estrategias de ahorro y planificación financiera.

Gracias a estos algoritmos, es posible desarrollar sistemas más seguros, organizados y eficientes.
